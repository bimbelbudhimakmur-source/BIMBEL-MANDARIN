Toggle ini berlaku real-time — efek langsung terasa di role Guru dan Admin
👨‍🎓 Guru boleh tambah & edit data murid sendiri
Ketika ON, guru bisa mendaftarkan murid baru dan mengedit data murid di kelasnya dari dashboard mereka
🏫 Admin boleh tambah kelas
Ketika ON, admin bisa membuat kelas baru di dashboard mereka
🗓️ Fitur Terkunci Otomatis (Berdasarkan Bulan)
Fitur berikut otomatis aktif di bulan tertentu. Kalau perlu buka di luar jadwal (situasi darurat), gunakan toggle "Buka Paksa".
